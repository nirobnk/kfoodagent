# Pinned, not ranged, and that is deliberate.
#
# This file used to carry loose ranges plus `langchain-core>=0.3,<1.0`. The
# langchain ecosystem then moved to core 1.x: langgraph 1.x, langchain-openai
# 1.x and langchain-google-genai 2.1+ all require langchain-core>=1.0. That cap
# made the requirement set unsatisfiable at any recent version, so pip walked
# backwards through every combination looking for one old enough — langgraph
# 1.2.11 down through 1.1.0, langchain-openai 1.6.2 down to 0.2.0 — and gave up
# after 200,000 rounds with ResolutionTooDeep. The Railway build spent eleven
# minutes on it before failing.
#
# The local venv had already resolved past that cap and was running
# langchain-core 1.6.3, so the file had not built this environment in a long
# time and nobody noticed until a clean machine tried.
#
# These are the exact versions the 226 tests pass against. Pinning them means
# what deploys is what was tested, and it resolves in about three seconds
# instead of exploring a combinatorial space. Bump deliberately, run the tests,
# commit the new pin.
