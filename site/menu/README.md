# K FOOD menu card

Open `menu-card.html` in a browser. The card reads product names, images, pack sizes, and all three price variants from `../products-data.js`, so catalog updates stay in sync automatically.

- Canvas: 1122 × 1402 px (portrait)
- Print/share styling: `menu-card.css`
- Generated decorative artwork: `assets/menu-background.png`
- Prices: LKR, with single-item, 5-pack, and carton pricing

Use the browser print dialog with margins set to **None** and background graphics enabled to export a PDF.
